## The goal

Collect the **text** of pages behind Cloudflare, for roughly **115,000–130,000 links** listed in the owner's spreadsheet. Treat it as one batch: the owner's own words are 115,000–130,000 link lookups. Only the page text is needed: no images, no data feeds. A residential proxy from Decodo is set up for the big run.

There's also a single-page watcher (`4.py`) that checks one page about every 90 seconds from the owner's home internet and reports changes. It was the first thing built, and it was tested on the owner's Mac.

## Rules the owner set (keep following these)

1. **Every file added to the repo is named with a number** (`1.md`, `2.txt`, `3.py`…). This folder is `7/` for the same reason.
2. **Never look at the owner's links.** They're private. The spreadsheet has them highlighted in black, and the scripts read them without ever printing them. Don't open the spreadsheet, ask for the links, or try to work out which site it is. The scripts' output shows only row numbers and "[your page]" or "[the site]".
3. **Never handle the proxy password.** It lives only on the owner's Mac at `~/decodo-password.txt` (file permissions `600`). Don't ask for it, and don't put it in the repo or a chat.
4. **The owner runs the scripts on their own Mac** (VS Code, Google Chrome installed). For tests they want a visible Chrome window so they can watch it work. AI tools in the chat can't see the owner's screen without seeing the address bar, so the owner presses Run.
5. **Don't look at the owner's other GitHub repositories.** Only `BrettS600/scrap` (private).
6. **No phone alerts.** The owner turned them down.
7. **Proxy handling was added only when the owner asked for it.** The owner said "get the proxy ready first, then I'll tell you what I want." The proxy is now ready, and the next instructions are still to come.
8. **Keep answers short and direct.** The owner wants plain recommendations, not lots of questions.

### Proxy details (no password)

- Provider: **Decodo** (formerly Smartproxy), Residential proxies, dashboard at dashboard.decodo.com.
- Settings in Proxy setup: Location **USA**, Session type **Sticky (30 min)**, Protocol **endpoint:port**, **10** endpoints.
- Address **`us.decodo.com`**, ports **`10001`–`10010`**. Each port is its own home IP, kept for 30 minutes.
- Username **`user-sp2e2o4qkx-sessionduration-30`**, lowercase `user`.
- Password: only in `~/decodo-password.txt` on the owner's Mac.
- Test command, which reads the password from the file:
  `curl -U "user-sp2e2o4qkx-sessionduration-30:$(cat ~/decodo-password.txt)" -x us.decodo.com:10001 https://ip.decodo.com/json`
- **Trial:** 100 MB. On 29 Oct 2026 the dashboard said it "converts in 4 days", so around 2 Nov 2026 it turns into a paid plan unless cancelled (⋯ menu next to "100 MB Trial"). The owner hasn't said yet whether to keep it.
- Lesson from setup: saving the password with `pbpaste > ~/decodo-password.txt` failed at first (proxy said 407), because copying the command overwrote the password on the clipboard. What worked was to paste the command, *then* copy the password, *then* press Enter.
